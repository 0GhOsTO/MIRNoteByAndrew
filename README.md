# [MIR Notes by Andrew](https://mir-note-by-andrew.vercel.app/)

Personal notes on **Music Information Retrieval (MIR)** — the field at the intersection of signal processing, machine learning, and musicology. After serving in the military and coming back with partial hearing loss, I started this project to understand sound computationally.

These chapters follow the [musicinformationretrieval.com](https://musicinformationretrieval.com) curriculum.

| 3 | Features and Applications | [chapter3.ipynb](chapter3.ipynb) |
